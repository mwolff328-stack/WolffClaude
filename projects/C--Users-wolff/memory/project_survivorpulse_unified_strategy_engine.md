Decided by founder 2026-06-29 during the My Strategy redesign. The Back Tester and the new Set Strategy feature are fundamentally the **same feature**: both answer "find the best strategy given a specific pools/entries setup." The ONLY real difference is the data source:

- **Back Tester** — uses historical games/spread/market data exclusively.
- **Set Strategy** — offers a choice between the same historical data OR forward projections of spread/market data for the current season (e.g. 4for4 lookahead lines, which land at `spreadFinalityTier = 'pre_kickoff_effective'`).
- **Modeled** path (synthetic pools/entries) must be available to BOTH features.

**Mandate:** there must be ONE strategy optimization engine that both features use — NOT the two that exist today (server `survivalCurveService`/`score100`/`roiProjectionService` which is currently strategy-blind on the greedy path, vs. the client backtester `assignIndependentPicks`/`backtesterSweepService` which holds the working advanced modes). Per CLAUDE.md §2.3 the engine should be a pure shared/core (zero DB imports, pure computation) fed by data-source adapters (historical / forward-projected / modeled).

**Consequences:**
- Full grid search over all ~30 `OPTIMIZATION_GRID` configs — including the advanced modes (coordinated diversification, adaptive blend, scarcity-aware) currently DEFERRED server-side — is in scope and is a primary differentiator. Founder accepted the timeline impact.
- `StrategyWeights.futureValueWeight` is dead config today (stored/validated/badge-only, never scored); the working FV lives in the backtester's separate `fvWeight` + `LEVERAGE_PROFILES.weightFV=0.25`. Unify under the one engine.
- Reframes the program into a keystone "Unified Strategy Optimization Engine" that Set Strategy, the Back Tester refactor (`task_a9e3a63e`), and the scoring/factors algorithm all sit on top of.

Specs affected: `docs/superpowers/specs/2026-06-28-set-pick-strategy-design.md`, `docs/superpowers/specs/2026-06-29-strategy-scoring-recommendation-algorithm-spec.md` (both predate this decision and must be revised), plus the Back Tester refactor initiative.
