Portfolio Lens risk dimensions were REDEFINED and ratified by the founder (with Marie Curie + Stan) on 2026-06-22. The original PROPOSED Dim 1/Dim 2 were mathematically collapsed (`correlationPct/100 ≡ concentrationHHI` — same Σshare² primitive shown twice). Ratified definitions (posted as comments on SST-568 and SST-564 Notion stories):

- **Dim 1 Correlation = FIELD-RELATIVE alignment**, not internal team-overlap. `fieldAlignment = Σ_t min(u_t, f_t) = 1 − ½·Σ|u_t−f_t|`, [0,1], per pool, aggregated across pools. V1 windows: W1 current-week vs ESTIMATED field, W2 season-to-date vs ACTUAL field. W3 (rest-of-season projected) = forecasting, DEFERRED. UI must say "estimated field" never "the field" (W1 reproducibility is conditional on a snapshotted estimate). **Severity direction RATIFIED 2026-06-24 (Marie+Stan reconciled): Dim 1 is a NEUTRAL posture metric (aligned↔contrarian / "crowd-mirroring", never "safe/risky") — no colour by default; high alignment NEVER reads green; soft "no leverage upside, some correlated-bust downside" caution; colour appears only once the user declares a strategy posture (mirrors Dim 3 neutral-without-target). Bands describe POSITION not severity. W1 field source = `poolPicksEstimationService.estimatedPickShare` (pool-scoped Bayesian Yahoo+pool-bias blend; NO new DB schema) — Felix confirmed.**
- **Dim 2 Concentration = ABSOLUTE attribute-clustering** (cliff-week risk). Per-attribute `maxShare`, headline = worst attribute, NO weighted composite in V1. V1 attributes: Chalk (field pick% ≥ 20%) + Home/Away. Deferred: spread, division, over/under, future-value.
- **Dim 3 Exposure UNCHANGED** (`actual%−target%`, bands 0.10/0.25).
- **Gates** (SST-564 cross-pool + draft soft-warn): strict `maxTeamShare > 0.50` (was `≥`) AND `stackedCount ≥ 2`. Value stays 0.50; flip `>=`→`>`. Known tradeoff: exact 2-of-4 (=0.50) no longer fires — founder accepted, "adjust if necessary". **DONE: SST-564-A (Notion ID SST-595) implemented + verified (94/94 tests) + pushed (commits 486e0441+b5e7e30b), status Done 2026-06-23. Learning on file: a soft-warn gate OR'd with a severity-band flag can be MASKED at its own threshold — the draft `hasRiskFlag` still trips at 0.50 via the concentration danger band, so the strict-gate's "0.50 no-fire" is only directly observable on the week-level cross-pool warning (my-picks).**

**Bands are NOT ratified** — old constants (CORRELATION 34/60, CONCENTRATION 0.34/0.50) retired; new bands DEFERRED until formulas are implemented and real distributions observed. Only the gate (>0.50) and Dim 3 are numerically settled.
