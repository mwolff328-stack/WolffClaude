The user's Claude Code configuration (~/.claude) is version-controlled in GitHub at https://github.com/mwolff328-stack/WolffClaude.git

A PostToolUse hook auto-commits and pushes changes to this repo whenever files under ~/.claude are modified.

**Important**: settings.json is gitignored because it contains a GitHub PAT.
