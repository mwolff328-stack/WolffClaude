When the same content-series post (e.g. the SurvivorPulse backtesting series) goes out across multiple channels, there is a fixed reference hierarchy:

1. **r/SurvivorPulse is the canonical, most-edited version.** The founder does his heaviest editing pass here — data tables, wording, structure, definitions of terms (e.g. "expected survival depth"). Treat the final, posted r/SurvivorPulse text as the source of truth for that post.
2. **Other SurvivorPulse-account channels (Discord, X) are derived from the r/SurvivorPulse version.** Adapt for platform constraints (Discord's 2000-char message limit and lack of markdown tables, X's length/format) but keep the same data, the same key sentences, the same definitions, in the same order they appear in the reference post. Don't independently re-derive phrasing or re-decide where a definition belongs — copy the reference post's structure and only change what the platform forces you to change.
3. **Non-SurvivorPulse-account public channels (e.g. r/NFLSurvivor) are then derived from the SurvivorPulse-account channel versions**, not from the r/SurvivorPulse original directly — one more hop down the chain (though in practice this mostly matters for tone/voice register, since r/NFLSurvivor cuts also switch to first-person from the founder's personal account, u/Cold_Issue_5093).

**Why:** the founder spends significant iterative time fine-tuning the r/SurvivorPulse draft (see the Post 5 session, 2026-09-04 — many rounds of edits on wording, table structure, definitions, bolding). Re-deriving each other channel's copy from scratch duplicates that editing effort and risks losing pieces that were deliberately placed (e.g. a definition was moved to a specific spot in the reference post, then that placement got lost when a Discord version split the content into separate messages and re-decided where the definition should go).

**How to apply:** when adapting a finished/approved r/SurvivorPulse post into Discord, X, or r/NFLSurvivor cuts, work sentence-by-sentence off the reference post's final text rather than reconstructing the argument independently. Splitting into Discord's multi-message format or condensing for X is fine, but do not relocate content (like a term's definition) to a different logical position than where it appears in the reference post unless there's a clear platform reason to.
