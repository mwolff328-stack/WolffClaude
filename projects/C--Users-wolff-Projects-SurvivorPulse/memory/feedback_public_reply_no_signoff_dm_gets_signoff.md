Public thread/comment replies (Community Post framework) should NOT end with a "Mike" sign-off. Cold DMs (private messages) DO get a sign-off, typically with contact info (e.g. "Cheers! survivorpulse.com @mrwolff369").

**Why:** Michael's explicit correction (2026-09-22): "People don't tend to sign-off on public posts." This matches the established AQfresh Community Post template, which ends on "Good luck this week." with no name sign-off, versus the Cold DM framework template which explicitly closes with a signed line.

**How to apply:** When drafting any outreach or reply in [[feedback_survivorpulse_authentic_tone_of_voice]] style, check the Framework first — Community Post / public thread reply = no sign-off; Cold DM = sign-off. Don't flag a missing sign-off as an omission on public-reply drafts.
