Invoke the `authentic-tone-of-voice` skill on every public-facing SurvivorPulse post draft (Reddit, Discord, X, or any other outward-facing copy) before treating it as final or publishing it — not only when the founder explicitly asks for a tone check.

**Why:** during the post-3 content-series session (2026-08-29/30), four channel drafts (r/SurvivorPulse, Discord, r/NFLSurvivor, X) were fully written, reviewed, edited, and published across multiple rounds before the founder had to ask "did we apply /authentic-tone-of-voice to this?" It had never been run. It turned out to pass clean, but that was luck, not process — the skill's own description at the time only said "use when setting up a new project or when AI output doesn't sound right," which doesn't read as an every-draft trigger. The skill's description was corrected the same session to explicitly name social/public content drafting as a trigger condition (see the skill file itself), but this memory exists as a second, project-scoped backstop in case that description drifts or gets missed.

**How to apply:** for any task that writes copy meant to go out under the SurvivorPulse brand or a personal account posting on its behalf (e.g. u/Cold_Issue_5093), run the skill before the draft is shown as "final" for founder sign-off, the same way [feedback_no_em_dashes_in_drafts](feedback_no_em_dashes_in_drafts.md) and the dollar-figure ban are already standing checks. Do this proactively, don't wait to be asked.
