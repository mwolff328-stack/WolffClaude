2026-07-27 research arc (Felix/Stan/Vlad): Game Plan Apply allocates picks via a deterministic greedy walk — pools sorted poolId asc, entries entryId (UUID) asc (`shared/strategyEngine/cockpitEntryPlans.ts:478,493`). A powered Monte Carlo proof gate (3,000 draws × 2021–2025 seasons, 80/80 parity-checked harness) showed allocation ORDER doesn't matter: cheap reorders ≈ 0 effect; Hungarian optimum only +0.03–0.05 survival weeks. Verdict: bless status quo, decline SE-85's portfolio optimizer (declined-with-evidence, not deferred).

**Why:** Prevents re-treating the UUID ordering as an unspecified accident or reviving the optimizer directive.

**How to apply:** Evidence + decision + implementation scope (spec comments + characterization tripwire test) live in SST-1070 (https://app.notion.com/p/3aa29ce5833d81268281d80cf09853bb), with Stan's and Vlad's full reports as sub-pages. Bonus proven result: "Spread picks across pools" default-ON is worth ~+1.4 survival weeks at 20 entries — citable direction-only (Curie governance, no ROI/EV claims). Multi-pick weeks still lack cross-entry distinctness (SST-1069, Backlog).

**SCOPE LIMIT — the blessing covers UNIFORM stakes only.** A follow-up arc the same day (founder question: ROI across pools with different fees/field sizes/prizes/payout structures) found the closed result does NOT generalize. Survival depth is *exactly* order-invariant (structural), so this is purely dollar redistribution — but with real stake spread, stake-descending entry ordering gains real money: at n=20, 7 of 8 scenarios significant (e.g. realistic mixed portfolio +$42.54, CI [18.50, 66.58]); patchy at n=10; unproven below. Use the FULL value proxy (`prizePool × topTierPct / max(1, fieldSize × avgFinalAliveFraction)`) — fee-alone is not harmful but is *blind* (literal 0.00 no-op) when fees match and field size/payout structure drive value; the `prize × topTierPct` compromise proxy is DISQUALIFIED. Zero-effect when spread toggle off and zero-harm under uniform stakes are both proven exactly (safety backstops). Groomed as **SST-1073** (epic SE-85), **SHIPPED** (verified 2026-08-01: `cockpitEntryPlans.ts` sorts the outer `poolIds` loop by `poolValuesById` descending when `spreadAcrossPools` is on and values are supplied, poolId-ascending as tiebreak) — pool economics are pool-level, so the inner entryId sort is UNCHANGED and the SST-1070 tripwire impact is ADDITIVE (its fixtures pass no economics → equal value → today's output), the new value param being optional. Founder rulings: ship unconditionally (no entry-count gate — uniform-stakes zero-harm is a STRUCTURAL proof); `avgFinalAliveFraction` = the empirical CONSTANT ≈0.00202, NOT live-wired (reversed after two findings: NFL odds aren't published a season ahead so a live derivation would fall back anyway, and the `max(1, fieldSize × frac)` denominator clamps to 1 below ~495 entrants — SST-1074 created for the derivation then Cancelled). Revisit trigger recorded on the ticket.
